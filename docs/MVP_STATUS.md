# AutoWatcher — фактическое состояние

## Статус продукта

Собрана версия для проверки локального приложения.
**Полный MVP по исходному критерию пока не подтверждён:** доступ к реальным Авито/Авто.ру
в среде проверки блокируется (429 / CAPTCHA). Это не заменено фиктивными результатами.

## Реализовано

- Общие прикладные сервисы для веб-панели и Telegram.
- CRUD фильтров, включение/пауза, выбор площадок, критерии и необязательные ссылки поиска.
- Сохраняемое расписание 1–1440 минут, ручная очередь, история и восстановление прерванных проверок.
- SQLite UPSERT, MATCH / NO_MATCH / UNKNOWN, атомарные страницы и outbox, дедупликация.
- Telegram: токен, одноразовая привязка владельца на 10 минут, команды и долгоживущие очереди.
- Retry/backoff уведомлений и ответов, повтор DEAD, обработка ошибок сети.
- Веб-панель: фильтры, результаты, история, настройки и автоматическое обновление состояния.
- Защита локальной сессии, Host/Origin, секреты не возвращаются через API.
- Очистка деталей и истории; идентификаторы и журнал совпадений сохраняются.
- Windows jpackage с Java Runtime, браузер, трей, скрипты автозапуска и блокировка второго экземпляра.
- Папка данных пользователя, корректное завершение Spring, ротация журналов.
- Новая миграция V3, исходные V1/V2 сохранены. Удалены закоммиченные файлы target.
- Maven Wrapper, Windows/Linux CI, браузерные проверки и тесты переносимого пакета.

## Известные границы

- Реальные источники не заменяются FAKE. FAKE включается только профилем demo.
- HTML-тесты используют контролируемые фикстуры и не доказывают живой парсинг.
- Без собственной ссылки используется общая выдача площадки и локальное сопоставление.
- На страницу — своя транзакция; успешные страницы сохраняются при сбое следующей.
- При аварии после отправки Telegram до ACK возможен повтор; в сообщении есть ID события.
- Идентификаторы и компактные журналы дедупликации сохраняются бессрочно.
- Система рассчитана на одного локального владельца и один процесс.

Подробная диагностика: [SOURCE_ACCESS.md](SOURCE_ACCESS.md).
