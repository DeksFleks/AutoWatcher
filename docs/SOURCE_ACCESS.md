# Доступ к Авито и Авто.ру

Дата проверки: 17 ноября 2026.

## Наблюдения

| Проверка | Результат |
|---|---|
| Авито: robots.txt | HTTP 200 в публичном PoC |
| Авито: выдача | HTTP 429, данные не получены |
| Авто.ру: robots.txt | HTTP 200 в публичном PoC |
| Авто.ру: простой HTTP PoC | HTTP 200, HTML/JSON-LD и маркеры карточек присутствуют |
| Авто.ру: полный цикл через Java-приложение | Перенаправление на CAPTCHA, разбор не подтверждён |

Доступность HTML для одного клиента не доказывает доступность для приложения.
Ни Авито, ни Авто.ру не отмечены как подтверждённые рабочие источники полного MVP.

Подтверждение:
- [Публичный PoC](https://github.com/DeksFleks/AutoWatcher/actions/runs/43978813084)
- [Проверка Java-адаптера и диагностика CAPTCHA](https://github.com/DeksFleks/AutoWatcher/actions/runs/43979761591)

## Поведение приложения

- Только публичные HTTPS-страницы выбранных доменов.
- Проверка robots.txt перед загрузкой, без разрешающего fallback при ошибке чтения.
- Один запрос источника одновременно, не чаще одного раза в 5 секунд.
- Таймауты, лимит размера ответа, до 10 страниц за проверку.
- При HTTP 429 учитывается Retry-After и включается пауза; повтор не выполняется немедленно.
- CAPTCHA и ограничения доступа не обходятся.
- Следование до трёх обычных перенаправлений внутри одного хоста; CAPTCHA-переадресация останавливает проверку.
- Неизвестная разметка даёт ошибку, а не ложную пустую выдачу.
- Пропущенные атрибуты остаются неизвестными; фильтр по отсутствующему атрибуту не считается совпадением.
- Телефоны, контактные профили и имена продавцов отдельными полями не извлекаются.
- Обычный CI не повторяет живые запросы. Отдельный запуск workflow_dispatch предназначен для диагностики изменений доступности.

## Условия использования и следующий шаг

robots.txt — технический сигнал для загрузчика; проверка не устанавливает наличие договорного разрешения.
Официальные страницы условий:
[Авито](https://www.avito.ru/legal/rules/terms-of-use),
[Авто.ру](https://auto.ru/legal/terms_of_service/).
Полные актуальные тексты этих страниц в среде подготовки надёжно получить не удалось;
разрешение на автоматизированную выгрузку не подтверждено.

Чтобы закрыть критерий реальных источников, нужен доступный и разрешённый канал данных:
официальный API/фид либо подтверждённый владельцем площадки способ чтения.
После этого требуется повторить именно полный цикл приложения и сохранить обезличенную
структурную HTML/JSON-фикстуру для регрессионных тестов.

## Исправление актуальной разметки, 17.11.2026

Свежая HTML-выдача `https://auto.ru/cars/ford/all/?query=Ford&from=searchline`
получена HTTP-клиентом среды с кодом 200 (773228 байт). Java-парсер после
исправления распознал 37 карточек с полями фильтра, nextCursor `?page=2`.
Это проверка реального HTML, но не подтверждение полного Java-сетевого цикла
на Windows. Старый селектор `.ListingItem` не охватывал новые карточки
`data-seo=listing-item`; новые цены используют `ListingItemUniversalPrice__title-*`.

Avito в этой среде возвращает HTML `Site Unavailable`, данных нет. HTTP 429
на машине пользователя остаётся внешним ограничением; добавлены понятная
диагностика VPN/прокси и поддержка Retry-After в формате HTTP-даты.
