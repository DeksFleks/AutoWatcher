Площадки

Без ссылки используется общая выдача площадки; свои ссылки помогут сузить поиск. Если площадка не отдаёт нужный параметр, результат будет «Недостаточно данных». Проверка доступа или изменение страницы появятся в истории.

Хранение данных

Детали старых объявлений очищаются автоматически. Идентификаторы сохраняются, чтобы не присылать одно объявление повторно.

Как работает поиск

Приложение читает доступные публичные страницы выбранных площадок. Автоматическая проверка может быть ограничена правилами сайта, CAPTCHA или изменением разметки. Такие ошибки видны в истории; приложение не обходит ограничения.

При закрытии браузера мониторинг продолжает работать. Выход — через значок AutoWatcher в системном трее или Ctrl+C в консоли.
